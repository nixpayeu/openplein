Wat is OpenPlein

Het WeChat-model, maar soeverein en open source

Grote platforms bundelen diensten in één app — handig, maar je levert je gegevens en je afhankelijkheid in. OpenPlein draait dat om: een open runtime waarin iedere Europese aanbieder een mini-app kan plaatsen, met de gebruiker als baas over elke permissie.

De shell

Een installeerbare web-app (PWA) met een catalogus van mini-apps, inloggen per e-mail en een permissiedialoog per gevoelige actie — zoals op je telefoon.

De bridge

Mini-apps draaien in een strikte sandbox en praten met de shell via één getypeerde API: pay, identity, storage. Geen permissie? Dan een nette foutmelding, nooit stille toegang.

Mini-apps

Gewone statische web-apps plus een klein manifest. Geen app-store-gatekeeper, geen native code, geen lock-in: wat je bouwt blijft van jou.

Voor bouwers

Een mini-app is een middag werk

De SDK scaffoldt een werkende mini-app; de bridge-API is drie methodes groot.

# scaffold
create-plein-app mijnwinkel

// betalen vanuit je mini-app
const plein = PleinBridge.createPleinClient();
await plein.pay({ amount: "2.50", currency: "EUR", description: "Koffie" });

De code is open source: github.com/nixpayeu/openplein — met daarin de volledige mini-app-specificatie (manifest, permissies, sandbox-eisen) in docs/miniapp-spec.md.

Soevereiniteit

Gebouwd op Europese bouwstenen

OpenPlein bouwt zelf alleen de dunne laag die nog niet bestond — de runtime en de bridge. De rest zijn verwisselbare Europese componenten:

betalen → Nixpay / Mollie identiteit → EUDI-wallet (eIDAS 2.0, roadmap) messaging → Matrix (roadmap) licenties → AGPL-3.0 + MIT

In English

The sovereign super-app runtime for Europe

OpenPlein is an open-source mini-app platform: one installable web app in which European services run as sandboxed mini-apps, behind a typed permission bridge (pay, identity, storage). We build only the thin missing layer and compose European building blocks — Mollie/Nixpay for payments, the EUDI wallet and Matrix on the roadmap. Licensed AGPL-3.0 (runtime, bridge) and MIT (SDK). Try the live demo (test payments only) or browse the source on GitHub.
